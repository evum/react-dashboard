# 008. Независимые скроллы дерева и таблицы

- Статус: принято
- Дата: 2026-09-16

## Контекст

На широком экране дерево и таблица стоят рядом. Длинное дерево не должно утаскивать шапку и соседнюю таблицу. На узком экране пользователь переключает вид, чтобы не сжимать обе панели.

## Решение

Колонка `height: 100vh` → шапка фиксирована в потоке → `Split` с `flex: 1; min-height: 0` → каждая `Pane` со своим `overflow: auto`.

От 1280px — CSS-grid две колонки (1fr / 2fr), обе панели видимы. Ниже — вкладки «Дерево / Таблица», невидимая панель `display: none`, состояние выбора и раскрытия общее.

## Альтернативы

- **Один скролл страницы** — шапка уезжает, панели связаны по высоте контента.
- **Виртуализация** (`react-window` и т.п.) — нужна на тысячах строк; сейчас мок меньше, зависимость не окупается.
- **Split-pane с ресайзом** — гибко, лишний UX и состояние ширины без требования.

## Последствия

- `scrollIntoView` выбранного узла скроллит только панель дерева.
- `display: none` на мобиле прячет панель, но не размонтирует таблицу: фильтр и сортировка живут.
- Горизонтальный скролл таблицы при узкой колонке — у панели, не у `body`.
